# 仕様書一覧

このフォルダは、現在の実装をもとに作成した Nature Remo 外出催促通知システムの仕様書です。

## ドキュメント構成

- `要求仕様書２.md`: システム全体の目的、構成、主要フロー、外部連携、状態遷移の仕様。
- `要求仕様書３.md`: リポジトリ内の各ファイルごとの責務、公開関数、入出力、例外、連携先の仕様。
- `要求仕様書４.md`: Script Properties、GAS マニフェスト、トリガー、デプロイ、運用確認の仕様。

## 対象ファイル

対象は次のファイルです。

- `Main.js`
- `SchedulerUseCase.js`
- `WebhookUseCase.js`
- `HealthCheckUseCase.js`
- `DomainModule.js`
- `ConfigRepository.js`
- `CalendarModule.js`
- `NatureModule.js`
- `NotificationModule.js`
- `StateModule.js`
- `LogModule.js`
- `appsscript.json`
- `.clasp.json`

## 前提

この仕様書は、Google Apps Script V8 ランタイム上で実行される現在のコードを対象にしています。外部サービスは Google Calendar、Nature Remo Cloud API、LINE Messaging API、Google Apps Script の Script Properties と Cloud Logging を利用します。
